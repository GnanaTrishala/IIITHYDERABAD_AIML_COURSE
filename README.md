# FMML_PROJECTS_AND_LABS
My project and lab submissions of FMML
This repository contains an extensive collection of machine learning notebooks developed as part of training and hands-on experimentation and working with real time projects during my time as an intern/trainee at ihub iiit hyderabad. It is designed to provide a structured progression from foundational mathematical concepts to advanced machine learning and deep learning techniques.

Each module focuses on both theoretical understanding and practical implementation, with detailed code, visualizations, and experiments on real-world datasets and also includes real time projects. The repository serves as both a learning resource and a reference for core machine learning concepts.

## Installation

### Clone the repository

```bash
git clone <your-repo-link>
cd FMML_PROJECTS_AND_LABS
```

### Create virtual environment

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Install dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn scipy plotly nltk jupyter
```

### Optional (Deep Learning)

```bash
pip install tensorflow keras torch torchvision opencv-python
```

---

## Running the Notebooks

### Option 1: VS Code

* Install Python and Jupyter extensions
* Open the repository folder
* Select interpreter
* Run `.ipynb` files

### Option 2: Jupyter Notebook

```bash
jupyter notebook
```

### Option 3: Google Colab

* Upload notebooks
* Run directly in browser

## Troubleshooting

* Ensure virtual environment is activated
* Install missing packages using pip
* Use `%matplotlib inline` if plots do not display
* Verify dataset paths are correct
